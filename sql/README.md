# SQL histórico — no desplegar

Estos scripts conservan el esquema anterior y contienen políticas inseguras. No son una vía de instalación ni actualización. Reejecutarlos puede reabrir el autoingreso y la escalación de privilegios.

Los cambios nuevos se versionan en `supabase/migrations/`. Consultar [Security Foundation](../supabase/SECURITY_FOUNDATION.md) para reconciliar instalaciones existentes y conocer las limitaciones actuales. La migración completa de OTP y otros componentes históricos sigue pendiente.
